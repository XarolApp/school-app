Before building or editing any frontend UI in school-app (components, pages, styling,
layout) — not just onboarding screens — read
`docs/sources/claude_code_ui_ux_guide.md` first.

**Why:** The user explicitly asked for this. The guide's psychological principles
(dopamine loops, IKEA effect, cognitive load, Norman's emotional design levels, etc.)
were originally merged only into the scoped [[onboarding-architect]] subagent, but the
user wants the same design thinking applied app-wide — general search/browse/detail
pages should feel like the same product as the onboarding flow, not a separately
designed bolt-on.

**How to apply:** Treat this as a standing instruction for the school-app project, not
a one-time read. Re-check the guide when starting frontend work in a new session or
touching a UI area not yet covered this session. `docs/sources/onboarding.md` is
archival only (fully merged into the agent file) — no equivalent standing-read
instruction applies to it. Also documented directly in the project's CLAUDE.md.
