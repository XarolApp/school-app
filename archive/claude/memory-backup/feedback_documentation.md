**Always update CLAUDE.md to reflect significant changes before ending the session.**

**Why:** Keeps project docs current and accurate for future sessions. The docs are the source of truth for what's been built.

**How to apply:** Whenever you add a new feature, change schema, restructure files, or make other significant changes, update the relevant sections in CLAUDE.md (typically "What's Already Built" and "What's NOT Built Yet") before wrapping up. This is a blocker for session completion, not optional.
