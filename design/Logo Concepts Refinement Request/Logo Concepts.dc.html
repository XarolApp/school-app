Střední na míru — logo system, round 1
Twelve directions, each one readable at 32 px
Concepts 1a–1d use the DESIGN.md system: terracotta #AD4F2A, moss #4F7143, warm paper, Lora + Public Sans. Concepts 1e–1h ignore that system entirely — their own palette and typeface each. Every mark is built from primitives (arc, rect, stroke), so each one is already clean vector and survives black, white, and a 40 px avatar circle. Concepts 1i, 1j and 1k are name-led: the wordmark itself is the logo, following the structure of the to dáš! mark you sent — written name plus a small caps qualifier — without borrowing its script or its teal. 1k is 1i rebuilt outside the DESIGN.md system, and 1l is 1j moved onto it. Tell me an id and I'll build the full asset set for it.
