Dark tooltip for optional detail — the definition of an abbreviation, the source of a figure.

```jsx
<Tooltip content="DiPSy — digitální přihlašovací systém pro střední školy.">
  <span className="sm-data-sm">DiPSy</span>
</Tooltip>
```

Do not put consequential interpretation here: inline bracketed interpretation comprehends far better than a tooltip. Anything that changes a conclusion goes inline.
