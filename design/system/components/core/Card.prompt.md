Neutral-fill card, 20px radius, soft tinted shadow. Use only for discrete objects.

```jsx
<Card interactive>
  <h3 className="sm-headline-sm">Gymnázium Jana Nerudy</h3>
  <p className="sm-body-sm">Praha 5 · státní · 4 roky</p>
</Card>
```

`raised={false}` swaps the shadow for a hairline border when cards sit inside an already-raised container.
