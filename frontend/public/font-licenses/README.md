# Bundled font notices

The website uses Archivo and Archivo Narrow from Fontsource 5.3.0.
Their copyright and SIL Open Font License 1.1 notices are copied unchanged from
those installed font packages:

- [Archivo](Archivo-OFL.txt)
- [Archivo Narrow](Archivo-Narrow-OFL.txt)

Vite copies this directory into the build. Keep both notices when distributing
these font files, and recheck the exact notices when updating the font packages.
